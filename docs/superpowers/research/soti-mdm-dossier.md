## Módulos y capacidades

**SOTI MobiControl** — EMM (Enterprise Mobility Management); también se posiciona como UEM.  
Soporta: Android, iOS/iPadOS, macOS, Windows, Linux.  
Capacidades clave verificadas:
- Enrolamiento express: Apple DEP, Android Zero-Touch, Samsung KME, Windows Autopilot, Zebra StageNow
- Geofencing con despliegue de políticas basadas en ubicación
- Control remoto (denominado "Remote Control" en la documentación; la velocidad de streaming no se anuncia públicamente como "60 FPS" ni "Blaze" con ese nombre en el marketing actual)
- Gestión de contenido vía SOTI Hub y SOTI Surf
- Despliegue y gestión de aplicaciones
- Gestión de OS y firmware
- Dashboard de salud del sistema
- **SOTI XTreme Technology** — tecnología interna de compresión y optimización de red que promete hasta 10× en velocidad de distribución de datos/apps para entornos de bajo ancho de banda. **No es un add-on de precios separado ni un "plan XTreme"**; es una característica disponible para suscriptores **Premium Plus** y **Enterprise Plus**. SOTI XTreme Hub es el componente de distribución local.  
  Fuente: https://soti.net/resources/blog/2020/accelerate-your-business-10x-with-soti-xtreme-technology/

**SOTI XSight** — Inteligencia de diagnóstico para minimizar downtime.  
No es solo "IoT/help desk": es una solución de soporte y diagnóstico para flotas de dispositivos móviles empresariales. Incluye control remoto en tiempo real, chat de texto/voz/video, gestión de tickets, analítica en tiempo real, y visualización de datos de dispositivos. Se integra con MobiControl.  
Fuente: https://www.soti.net/products/soti-xsight/

**SOTI Snap** — Plataforma no-code/low-code para crear apps móviles multiplataforma (iOS + Android) mediante drag-and-drop; soporta +100 idiomas, funciona offline, incluye IA para digitalizar formularios PDF.  
Fuente: https://www.soti.net/products/soti-snap/

**SOTI Connect** — Gestión del ciclo de vida de **impresoras móviles e industriales** (no IoT genérico). Multivendor. Tiene capacidad de descubrir otros dispositivos en red, pero el foco es impresoras.  
Fuente: https://www.soti.net/products/soti-connect/

**SOTI Identity** — IAM centralizado: SSO, gestión de roles y acceso unificado a toda la suite SOTI ONE.  
Fuente: https://www.soti.net/products/soti-one-platform/

**Opciones de compra verificadas en soti.net/solutions/mdm/:**
1. SOTI MobiControl (solo EMM base)
2. MobiControl XS (MobiControl + XSight)
3. MobiControl Snap (MobiControl + Snap)
4. ONE Platform (suite completa)
