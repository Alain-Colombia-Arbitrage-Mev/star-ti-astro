## Línea de producto

### Nombre oficial vigente (2025-2026)

Stellar Cyber no usa un nombre de producto único. Usa simultáneamente varias denominaciones:

| Denominación | Dónde aparece |
|---|---|
| **Stellar Cyber SecOps Platform** | Homepage hero, `/platform/` |
| **AI-Native Security Operations Platform** | `/platform/` heading |
| **Automation-driven SecOps Platform** | `/product/` heading |
| **Open XDR** | Categoría de arquitectura; Gartner Peer Insights product name: "Open XDR Platform" |
| **Human-Augmented Autonomous SOC Platform** | Posicionamiento 2025 (RSAC 2025, release 6.0.0) |

**Conclusión verificada:** El nombre paraguas actual es **"SecOps Platform"** (con adjetivos: AI-Native, Automation-driven). "Open XDR" sigue vigente como arquitectura y categoría de analistas, NO desplazó al primero — ambos coexisten. El tagline oficial actual es **"See. Know. Act."**

**Posicionamiento 2025:** La narrativa dominante desde RSAC 2025 y la release 6.1 es **"Human-Augmented Autonomous SOC"** impulsado por **Agentic AI**.

### Motor de IA: Multi-Layer AI™

Nombre registrado: **Multi-Layer AI™** (trademark). Cuatro capas oficiales:

1. **Detection AI** — ML supervisado y no supervisado para detección de amenazas
2. **Correlation AI** — Tecnología GraphML que conecta alertas entre fuentes
3. **LLM-Driven AI** — GenAI conversacional para investigación (= "AI Investigator Engine")
4. **Agentic AI** — Playbooks adaptativos con agentes autónomos

### Agentes nombrados (release 6.0, julio 2025)

Cinco agentes especializados anunciados en RSAC 2025:
- **Triage Agent**
- **Discovery Agent**
- **Correlation Agent**
- **Scoring Agent**
- **Response Agent**

### Sobre MTTD/MTTR
**Advertencia verificada:** Stellar Cyber NO publica métricas cuantificadas de MTTD/MTTR en su sitio actual. La web usa lenguaje genérico: "Reduce MTTD and MTTR with automated incident workflows". Las únicas métricas cuantificadas publicadas son:
- "Up to 400% reduction in threat response times" (AI Investigator, en la página Multi-Layer AI)
- "Reduces analyst decisions to 10-100/day"

Cualquier otra cifra (ej. "8x más rápido", "80% reducción alertas", "72h → 4 min") NO está publicada en stellarcyber.ai y no debe atribuirse a Stellar Cyber como cifra oficial.
