## Módulos y capacidades

### 1. Triple Layer Security (nombre oficial de Brother)

Brother documenta tres capas de seguridad para dispositivos en red:

**Capa 1 — Seguridad de red:**
- IPsec (túneles cifrados)
- IEEE 802.1x Authentication
- SNMPv3 (gestión de dispositivo cifrada)
- IPPS con TLS (cifrado de datos de impresión en tránsito)
- SFTP/SSH con RSA + Public Key Authentication para escaneo seguro

**Capa 2 — Seguridad de dispositivo:**
- Setting Lock (contraseña de configuración)
- Secure Function Lock (restricción de funciones por usuario)
- Sin disco duro interno (elimina riesgo de retención de datos en equipos enterprise)
- Firmware protection

**Capa 3 — Seguridad de documentos:**
- **Secure Print** (retención de trabajo hasta autenticación PIN en el equipo)
- **Secure Print+** (requiere login del usuario en el dispositivo — add-on opcional)
- **NFC Badge Authentication** (liberación walk-up sin lectores externos)
- **Active Directory Print Release** (credenciales de red para recoger documentos)
- **Active Directory Authentication** (verificación de usuario y restricción de funciones)
- IP Filtering (whitelist/blacklist de acceso al equipo)
- Syslog Report (alertas a herramientas SIEM)

**Certificación independiente:** BLI Security Validation Testing seal de Keypoint Intelligence (pruebas de penetración de firmware, OS, puertos, protocolos, página web embebida).

**Fuente:** https://www.brother-usa.com/solutions/security-solutions | https://www.brother-usa.com/solutions/device-management-security

### 4. Managed Print Services (MPS)

Proceso de 5 etapas documentado: **Assess → Design → Implement → Manage → Optimize**

- Gestión externalizada de flota: evaluación, reposición de consumibles, soporte continuo
- Monitoreo remoto de niveles de consumibles en dispositivos en red
- Reducción de residuos y consumo de papel/tóner
- Autenticación de dispositivo + cifrado + liberación autorizada de documentos

**Programas oficiales:**
- **Brother Authorized Partner Program (BAPP)** — canal de distribución y MPS
- **Value Print Program Plus (VPP+)** — monitoreo remoto basado en nube, descuentos en consumibles, gestión de configuración de dispositivos
- **Printing Value Program (VPP)** (LatAm) — descuentos en productos auténticos + extensión de garantía en modelos seleccionados
